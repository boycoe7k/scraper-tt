ZIMSEC Papers API

Programmatic access to the searchable archive of ZIMSEC past papers, marking schemes and study resources.

GETTING STARTED

Quick start

All read endpoints return JSON and require no authentication. Replace the base URL below with your Render service URL when calling the API from another application.

curl "/api/papers?level=O%20Level&limit=20"
TipUse URL encoding for spaces and special characters in query parameters. The maximum page size is 500 papers.
GET/api/health

Returns service status, crawler state, source URL and the latest scan summary.

{
  "ok": true,
  "running": false,
  "source": "https://zimsecpapers.github.io/",
  "state": { "lastScan": "2026-09-10T18:00:00.000Z", "foundPdfs": 538 }
}
GET/api/stats

Returns archive totals and the available values for level, subject and year filters.

{
  "total": 538,
  "oLevel": 350,
  "aLevel": 188,
  "subjects": ["Mathematics", "Physics"],
  "years": [2024, 2023],
  "lastScan": "2026-09-10T18:00:00.000Z"
}
GET/api/papers

Search and filter papers. Results are ordered with the newest discovered papers first.

qSearch title, subject, level, session or type.
levelO Level or A Level
subjectExact subject name, such as Mathematics.
yearFour-digit examination year.
sessionJune, November or May.
typePaper, Marking Scheme, Green Book, Blue Book or Notes.
limitNumber of results, from 1 to 500. Defaults to 100.
curl "/api/papers?q=chemistry&year=2012&limit=10"
{ "total": 1, "papers": [{
  "id": "a1b2c3...", "title": "ZIMSEC A Level Chemistry...",
  "url": "https://...pdf", "level": "A Level",
  "subject": "Chemistry", "year": 2012,
  "session": "November", "paper": "Paper 6", "type": "Paper"
}] }
GET/api/papers/:id/download

Downloads the locally cached PDF when available. If it is not cached, the request redirects to the original source PDF.

curl -L -o paper.pdf "/api/papers/a1b2c3.../download"
POST/api/scrape

Starts a manual crawler run. This endpoint is intended for administrators and is protected when SCRAPE_KEY is configured in Render.

curl -X POST \
  -H "x-scrape-key: YOUR_SCRAPE_KEY" \
  "/api/scrape"
Keep your key private.Do not place SCRAPE_KEY in browser code, public repositories or client-side applications. Store it as a Render environment variable.
